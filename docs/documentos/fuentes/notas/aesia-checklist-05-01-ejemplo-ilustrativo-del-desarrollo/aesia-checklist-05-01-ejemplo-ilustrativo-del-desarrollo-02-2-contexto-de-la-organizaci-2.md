# 2.Contexto de la organizaci (2)

| Sistema | Elementos clave alrededor de la salud, seguridad y derechos fundamentales de las personas | Elementos del contexto |
|---|---|---|
| Sistema de IA para la promoción de empleados | Derechos fundamentales (No discriminación) | El sistema de IA para la promoción de empleados se alinea con las políticas organizativas de no discriminación e igualdad de oportunidades. Las decisiones se basan en criterios objetivos, transparentes y explicables, y están supervisadas por humanos, fomentando así la confianza en su uso. El sistema ha sido entrenado con datos diversos y validados, asegurando su calidad y representatividad, y se implementan medidas proactivas para identificar y corregir posibles sesgos en los algoritmos. El sistema fomenta la comunicación abierta, ofreciendo a los empleados la posibilidad de presentar alegaciones y proporcionar retroalimentación (feedback). De este modo, se asegura un espacio para la revisión y, cuando sea necesario, la rectificación de las decisiones tomadas. |
|  | Derechos fundamentales (Protección de datos de carácter personal) | El sistema de IA cumple con el Reglamento General de Protección de Datos (GDPR), asegurando la privacidad y seguridad de los datos personales. La recopilación de datos se realiza únicamente con el consentimiento explícito de los empleados, quienes son informados de manera clara sobre el tratamiento y la finalidad del uso de su información. |
| Gestión de enfermedades crónicas - Bomba de insulina inteligente | Salud y seguridad | Este sistema de IA utiliza algoritmos para analizar datos en tiempo real de niveles de glucosa, actividad física y patrones de alimentación, ajustando automáticamente las dosis de insulina según las necesidades concretas del paciente. Para garantizar la transparencia del sistema, se proporciona a los usuarios y a los profesionales de la salud información clara y comprensible sobre las decisiones y ajustes realizados por el sistema. Para prevenir riesgos, se realizan análisis continuos para identificar y corregir posibles fallos en los algoritmos o desviaciones en su funcionamiento. El sistema incluye también alertas proactivas que notifican al paciente y al equipo médico en caso de detectar patrones inusuales o emergencias. |
|  | Derechos fundamentales (Protección de datos de carácter personal) | El uso de datos personales se realiza de forma responsable, con el consentimiento explícito del paciente, y siempre alineado con el Reglamento General de Protección de Datos (GDPR). Además, el sistema es sometido a auditorías periódicas para verificar el cumplimiento de estas normativas y garantizar la privacidad y la seguridad de la información de los pacientes. |
